# 🛍️ Retail Sales

## About This Project

This repository contains my Retail Sales Data Agent project completed using Databricks.

The project involved exploring a retail sales dataset using SQL and testing a Data Agent by asking business-related questions about the data.

---

## 🛠️ Tools Used

- Databricks
- SQL
- Data Agent
- GitHub

---

## 📂 Repository Contents

### 📊 Raw Retail Sales Dataset
The original retail sales dataset used for the project.

### 💻 SQL Data Checks
SQL queries used to explore and check the dataset before working with the Data Agent.

The queries include:

- Viewing the dataset
- Checking the data structure
- Counting records
- Checking for missing values
- Checking for negative or unusual values

### 🤖 Data Agent Questions & Answers
Screenshots of the 10 questions asked to the Retail Sales Data Agent and the responses generated by the agent.

The questions cover different business aspects of the retail sales data and were used to test the Data Agent's ability to respond to business-related questions.

---

## 🎯 Project Focus

The project focused on:

- Exploring retail sales data
- Performing basic data-quality checks using SQL
- Working with a Data Agent in Databricks
- Asking business questions using natural language
- Capturing and documenting the Data Agent's responses
